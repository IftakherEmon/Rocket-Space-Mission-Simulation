# 🚀 Rocket Space Mission Simulation

An interactive 3-scene OpenGL simulation of a complete rocket space mission from launch to moon landing.

## 🎮 Controls

| Key | Action |
|-----|--------|
| `1` | Scene 1: Rocket Launch from Earth |
| `2` | Scene 2: Rocket Separation in Space |
| `3` | Scene 3: Moon Landing |
| `A` | Release Astronaut (Scene 3) |
| `ESC` | Exit Program |

## 🎬 Scenes

### Scene 1: Rocket Launch 🚀
- Rocket launches from Earth with smoke effects
- Vertical upward movement
- Launchpad and sky background

### Scene 2: Space Separation 🌌
- 6-stage rocket separation sequence
- Parts separate in different directions
- Stage-wise text messages
- Star background

### Scene 3: Moon Landing 🌙
- Rocket descends to moon surface
- Twinkling stars
- Astronaut walks on moon after landing

1. Install Code::Blocks with GLUT
2. Clone this repository
3. Open `.cbp` file
4. Build and Run (F9)
